# Module Overview

| Module | Source file | Function |
| --- | --- | --- |
| AMKF | `mkf_rtdetr/blocks.py` | Adaptive multi-scale kernel fusion with five depthwise-separable branches, post-fusion 1x1 projection, dual-path attention, and Sigmoid channel calibration. |
| C2fAMKF | `mkf_rtdetr/blocks.py` | C2f stage wrapper that uses AMKFBlock as its repeated internal transform for backbone stages 3--5. |
| EPLA | `mkf_rtdetr/blocks.py` | Four `Q(K^T V)` polarity branches, channel concatenation and projection, real-valued `rFFT/irFFT` frequency enhancement, and multi-scale local convolution. |
| ESRCA | `mkf_rtdetr/blocks.py` | Multi-scale rectangular self-calibration attention: ordinary 5/11/21 strip convolutions plus a parallel depthwise 5x5 local branch. |
| Bi-Fuse | `mkf_rtdetr/blocks.py` | Bidirectional attention fusion between high-level semantic and low-level spatial features. |
| ESRFPN | `mkf_rtdetr/blocks.py` | 640-channel Enhanced PCE, three RCM-ESRCA branches, and top-down/bottom-up Bi-Fuse producing P3/P4/P5. |
| MKFHybridEncoder | `mkf_rtdetr/model.py` | Integrates EPLA and ESRFPN between backbone feature outputs and the RT-DETR decoder. |

For an `800x800` input, the model accepts `S3` (`100x100`), `S4` (`50x50`), and
`S5` (`25x25`), then produces three 256-channel feature maps `P3`, `P4`, and
`P5` for the RT-DETR decoder.

At `N=25x25=625`, the real FFT has `313` independent complex frequency bins.
The BCHW/BNC adapter around EPLA performs layout conversion only and does not
append a residual/LN/FFN transformer shell. ESRFPN is the complete
three-input/three-output implementation; no single-input compatibility block is
part of the formula-aligned path. Projection layers and stride-2 downsampling
are plain convolutions without implicit BN or activation.

Code defaults that should also be stated in the manuscript are: EPLA
`heads=8`, `p=3`; local SE reduction `16`; PCE reduction `16`; ESRCA scale
reduction `4`; and RCM MLP ratio `2`, layer scale `1e-6`. These choices are
implementation defaults, not values currently specified by the manuscript.

The formula-aligned graph is incompatible with old checkpoints and must be
retrained. Validation scripts are provided, but no local PyTorch forward-pass
claim is made here.
