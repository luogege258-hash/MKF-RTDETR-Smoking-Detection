# Module Overview

| Module | Source file | Function |
| --- | --- | --- |
| AMKF | `mkf_rtdetr/blocks.py` | Adaptive multi-scale kernel fusion with five depthwise convolution branches, kernel selection, dual-path attention, and channel calibration. |
| EPLA | `mkf_rtdetr/blocks.py` | Polarized linear attention with frequency enhancement and multi-scale local convolution branches. |
| ESRCA | `mkf_rtdetr/blocks.py` | Multi-scale rectangular self-calibration attention using directional strip convolutions. |
| Bi-Fuse | `mkf_rtdetr/blocks.py` | Bidirectional attention fusion between high-level semantic and low-level spatial features. |
| ESRFPN | `mkf_rtdetr/blocks.py` | Enhanced feature pyramid that produces the P3/P4/P5 feature maps. |
| MKFHybridEncoder | `mkf_rtdetr/model.py` | Integrates EPLA and ESRFPN between backbone feature outputs and the RT-DETR decoder. |

The model accepts backbone features `S3`, `S4`, and `S5`, then produces three
256-channel feature maps `P3`, `P4`, and `P5` for the RT-DETR decoder.
